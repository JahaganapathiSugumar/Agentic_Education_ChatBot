## 💡 Pro Tips

### For Dark Mode
- Primary: `#10a37f` (green)
- BG: `#040404` (true black)
- Surface: `#212121` (elevated)
- Text: `#ececec` (primary)

### For Smooth Animations
- Use `duration-fast` for interactions (150ms)
- Use `duration-base` for transitions (200ms)
- Use `animate-fade-in` for entrances

### For Premium Feel
- Always add shadows on hover
- Use gradient backgrounds
- Round corners appropriately
- Add focus rings for keyboard nav
- Respect reduced motion preference
